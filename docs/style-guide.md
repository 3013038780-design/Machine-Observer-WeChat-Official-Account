# 排版基准

当前基准来自桌面现用 assets/theme.json，2026-09-12 原样归档。用户确认沿用既有排版习惯；下列数值由当前配置读取，尚未再次逐项确认。

| 项目 | 当前基准 |
|---|---|
| 正文 | 16px，#333333，两端对齐 |
| 正文行高 | 1.75 |
| 字间距 | 0.5px |
| 正文段间距 | 上下各 18px（实际相邻间距以浏览器渲染为准） |
| 正文两侧留白 | 各 12px |
| 主标题 | 22px，行高 1.5，居中，上 36px / 下 30px |
| 章节标题 | 18px，行高 1.55，上 44px / 下 18px，底部留白 10px |
| 小标题 | 17px，行高 1.5，上 28px / 下 14px |
| 强调色 | #B91C1C |
| 辅助红 | #C0392B |
| 底色 | 白色 #FFFFFF |
| 浅色卡片 | #FAFAFA、#FDF6F5 |
| 分隔线 | #E5C4C0 |

以充分留白、适度强调和清晰章节建立阅读节奏。红色用于重点与少量装饰，不让大面积色块压过正文。正文不能为了塞表格而不断缩小字号。

## 旧组件差异

references/components-legacy.md 原样保留历史组件库，其中正文为 14.5–15px、行高 1.85、字距 0.3px，与当前主题不同。引用组件时统一正文为 16px / 1.75 / 0.5px；来源、小字注释和事实卡可使用专用字号。不可让 raw HTML 的历史内联样式悄悄覆盖当前正文基准。

## HTML 与 135

- 正文使用内联 CSS，不依赖外部字体、外部样式、脚本、class 选择器。
- 简单 section、段落、边框和卡片；避免复杂定位、动画及 flex/grid 排版。
- 横向宽表优先拆分，确保手机阅读。
- 交付的是打开后可复制的排版正文，不是要求用户粘贴源码。
- 兼容性需要预览；历史组件说明中的“绝对安全”表述不是对所有编辑器版本的保证。
