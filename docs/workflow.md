# 工作流与写作约定

记录日期：2026-09-12。当前执行顺序已按用户最新反馈改为“大纲审核→纯文字审核→排版”，优先于下方历史记录中的HTML优先及保留旧结构要求。依据当前用户指令，以及桌面“公众号/公众号写作美化”内既有流程整理。

## 当前明确要求

- 品牌：旁观机器 / Machine Observer。
- 新定位待讨论，保留历史资料但不沿用为硬约束。
- 采用客观叙述；不写作者个人背景、个人学习动机或朋友从业经历。
- 一篇围绕一条主线，先保证阅读节奏；型号、术语和价格明细可进入附表。
- 先审核写作逻辑与大纲，再审核完整纯文字稿；用户认可文字后才制作 HTML、表格图片与135排版。
- 每篇文章的框架、资料、拟稿到最终稿及配套资产都进入 GitHub。

## 执行顺序

1. 确定写作逻辑：先写一句话说明文章回答什么、读者读完能理解什么；明确唯一的正文组织轴（例如产品线、时间或问题递进），以及不在本篇展开的内容。
2. 提交大纲审核：用户提供的图片、文章和目录先作为待核查参考，不自动当作内容要求或可靠分类；区分官方事实与编辑分组。每节列出核心问题、准备给出的答案、必需的例子及与上一节的关系。同级标题必须使用同一种分类标准；用途、角色、技术、价格不能未经说明地混为平级分类。大纲未经用户认可，不直接扩写整篇。
3. 研究核查：围绕大纲收集一手资料。型号、状态、价格与数字记录来源、版本、日期和口径。研究可与大纲审核并行，但不能用搜到的材料反向堆成文章。
4. 纯文字拟稿：大纲确认后写完整Markdown供用户审核。每段只承担一个明确任务；先解释是什么、有什么用，再补必要机制和实例。每个术语必须能回答“读者为什么需要知道”；只查阅用的细节放附录。表格用于比较，不代替正文说明。
5. 全文编辑复核：完成后从头连读，检查主线、层级、过渡、重复、概念范围和读者负担。局部反馈先判断是措辞问题还是结构问题；结构被否定时重做大纲，不能只搬段落、换标题。行业观点必须解释具体问题，不能为增加深度而插入无关评论。
6. 文字审核与修订：交付纯文字全文，清楚标注待审阅。根据用户反馈修改；未经文字认可，不推进HTML、配图和表格图片。不能把排版通过当作文章内容通过。
7. 排版与检查：文字认可后使用assets/theme.json与docs/style-guide.md生成内联HTML，按需要生成紧凑手机表格图片。检查手机预览与桌面展示；未实测135粘贴时如实说明。
8. 交付与归档：大纲、资料、文字版本、审核状态及后续HTML/图片分阶段归档GitHub并核实同步。用户复制渲染正文到135，图片可单独上传。只有明确认可的稿件才标为定稿，发表需要另行明确指令。

## 文件组织

每个专题使用 articles/<日期-专题>/，可包含：

- brief.md：需求、范围、大纲、标题候选及确认状态。
- research/：信源记录、事实核查、价格记录与合法保存的资料。
- upper/ 与 lower/：上下篇源稿、HTML 和版本说明；单篇无需分上下目录。
- assets/：本专题配图、图表及素材来源说明。
- CHANGELOG.md：稿件状态、主要修改、数据核实日期、发布状态。

研究资料以可追溯链接、必要摘录和整理笔记归档；不自动镜像第三方全文或受限资料。

## 与历史流程的区别

旧 SKILL.md 包含公众号 API 凭证配置、确认后才渲染、上传草稿箱等路径。用户自行复制到135，本仓库不执行上传草稿箱等无关步骤，也不读取旧凭证。最新顺序为先大纲、后文字审核、再HTML排版。

桌面旧文件保留。此次不是历史资料全量迁移，也不意味着旧稿已经正式发表。

## 开篇提要 · 2026-09-12

用户要求本篇在正文前加入内容提要，概括主要观点。提要应交代文章范围和核心判断，保持简洁，与既有绿色排版协调。

## 基础科普 · 2026-09-12

用户要求对文章涉及的 CPU、GPU、显存、内存、带宽等基础概念给出解释，包括英文全称。适合对照的内容列成手机可读表格，表后结合实际工作过程解释关系，不能假定读者已掌握术语。

## 研究先于结构定案 · 2026-09-12

- 在候选大纲定案前完成范围调查：官方目录用于确定对象与关系，原始访谈用于了解观点，独立测试用于约束性能判断。不能只查几张产品页便声称完成深度研究。
- 保存阅读边界：实际阅读章节、公开/付费限制、厂商提供设备或数据、测试软件版本；未复现测试不得声称自行验证性能。
- 将调查全量材料与正文取舍分开。图谱的分组不是用户要求，也不是官方分类；同级分类必须说明依据，跨层关系须交代。
- 最新目录、历史发布、供货公告和实际现货不能混用。官方页面有字段冲突时也需核查，不机械照抄。
- 每个候选章节交代问题、答案、必要例子和前后关系；先提交可审阅的大纲，认可后才扩写正文。
