# AI 协作交付物探索清单 v4

日期：2026-10-23。状态：重梳清单，供讨论；未改 article-v4.md、全文 HTML 或图片。这里的 v4 是清单版本，与文章 v4 分开。

## 这一版怎样组织

先看拿到什么，再用具体作品说明它可以是什么样。每行写一类能够明确约定、交给使用者使用的成果；名称后面的例子帮助想象，不继续拆成功能目录。行内可以包含用途不同、但交付与使用方式相近的作品。

分组是阅读导航，不是一套互斥的行业分类；一项项目可以组合多类成果。网站、游戏等名称也不处在同一套软件技术分类中，但分别提供读者熟悉且有明确使用方式的成果入口。不能将导航分组或表格行数宣称为“AI 所能交付的全部种类”。本版不以总数为标题卖点。

拆分依据是拿到的对象、进入方式或后续使用动作存在值得读者认识的差别。只换题材、业务用途、界面功能、触发时间或模型数量，一般不另起一行。一个游戏的背包和存档不拆项；一套可独立导入的游戏资产可以另列。图像成品和分层设计工程分开说明，因为查看成图与继续修改对象是不同的交付要求；源文件本身不是包揽所有类别的新类别。

网站里的计算器、看板、库存管理都可以是完整作品，在本清单作为网页应用的具体例子，不按功能逐个扩项。iOS/Android、菜单栏/托盘、本地/云端、定时/事件触发，也分别作为平台、入口、部署和启动条件，不再靠这些属性增加行数。

以下例子是供交办和选材的设计示例，未在本轮实际制作或验证。工具与接口的必要条件集中在每组后，制作时用了 AI 不表示成品运行必须接模型。

## 一、能直接打开或进入的应用

| 可以交付什么 | 拿到什么、怎样用；具体作品例子 | 可以这样跟 AI 说 |
| --- | --- | --- |
| 网站与网页应用 | 网页工程及约定的可访问版本；浏览器打开。作品集、交互报告、预算计算器、数据看板、预约或库存系统都是例子，不继续拆成独立种类。 | 把这些产品资料做成可筛选的比较网页，结论能回到来源，附打开和修改方法。 |
| 手机和平板 App | 目标系统的应用工程及约定的测试或安装版本；从设备入口使用。例：打包清单、计时、随手记录。 | 做一个手机出行清单 App，能勾选并保存；先说明适用系统，交可测试版本和源工程。 |
| 桌面应用 | 电脑上的可运行应用及工程；窗口、菜单栏、托盘是入口选择。例：图片整理、专注计时、本地笔记。 | 做一个电脑图片整理工具，选文件夹后能预览并执行改名，说明适用系统。 |
| 平台内小程序或轻应用 | 指定平台的工程、配置与测试入口；在微信等目标宿主内进入。例：活动报名、预约、报修。 | 做一个微信内使用的预约小程序，先做可测试版本，说明后台和平台条件。 |
| 游戏与互动作品 | 可以实际游玩的版本及源工程；例：点击解谜、互动故事、分支课程。背包、存档、排行榜等作为玩法需求，不逐项列入清单。 | 做一个三次选择的互动故事，能重新开始，交运行版、分支结构和编辑方法。 |
| AR/VR 空间应用 | 面向约定设备的体验程序及工程；人在支持设备中观察、移动或操作。例：虚拟展厅、空间教学体验。 | 为指定设备做一个可体验的虚拟展厅，先核对设备条件，再交可运行小样和工程。 |

条件：应用要对应的开发、构建和运行环境；安装、签名、设备权限、后台与分发按目标核对。PWA 是网页应用可采用的安装/离线方案，不单列为一种作品。浏览器三维展示、搜索知识站、在线问卷、网页地图，也可放进网页应用的例子中。基础功能不默认需要模型；同步、实时数据、地图等连接按任务安排。

## 二、装进现有软件里的扩展

| 可以交付什么 | 拿到什么、怎样用；具体作品例子 | 可以这样跟 AI 说 |
| --- | --- | --- |
| 浏览器扩展 | 扩展工程、安装方式与权限说明；在浏览器按钮、侧栏或页面里使用。例：摘录、标注、页面整理。 | 做一个浏览器摘录扩展，保存选中文字、网址和备注，并能导出。 |
| 办公软件插件或宏 | 指定办公软件可加载的插件、宏或脚本；直接处理原文档与表格。例：重复项检查、格式整理。 | 给这份工作簿做一个原表重复项检查工具，说明兼容的软件与安装方法。 |
| 编辑器扩展 | 指定代码编辑器可安装的扩展包及工程；执行命令或打开面板。例：失效链接检查。 | 为指定编辑器做一个链接检查扩展，能定位项目中的失效链接。 |
| 设计与三维软件插件 | 对应软件的脚本或插件工程；在制作环境里调用。例：批量排版、模型导出。 | 做一个 Blender 批量导出插件，选择对象后按约定命名，保留设置。 |
| 网站系统插件 | 指定网站系统可安装的插件与配置说明；在网站后台及页面使用。例：报名表、内容管理扩展。 | 给指定网站系统做活动报名插件，交可安装版本、字段配置和测试样例。 |
| 系统扩展与小组件 | 可加载的桌面卡片、右键动作或系统扩展工程；使用系统提供的入口。例：日程小组件、文件快捷操作。 | 为指定系统做桌面日程小组件，交工程、加载方法和支持条件。 |
| 游戏模组与关卡包 | 指定游戏或编辑器可导入的扩展包及工程；在已有游戏环境使用。例：独立关卡、规则模组。 | 为指定游戏做一个可安装的新关卡包，先核对编辑支持，交安装方法和源工程。 |

条件：这些行按安装宿主区分，宿主、版本与扩展能力影响实际交付方式。插件名称必须带出安装位置。普通规则功能不必接模型，摘要、联网查询等另配相应连接。可导入系统快捷指令若是流程定义，放下一组；本组说的是系统可加载的扩展工程。游戏里的一个按钮功能不单列，可独立导入的关卡/模组包则有明确的接收对象和使用方式。

## 三、能重复执行、接入或复用的程序工程

| 可以交付什么 | 拿到什么、怎样用；具体作品例子 | 可以这样跟 AI 说 |
| --- | --- | --- |
| 可重复运行的处理程序 | 脚本或可执行工具、参数说明与样例；用终端或指定运行入口处理新输入。例：照片批处理、数据清洗、证书生成、网页自动录入、程序化动画生成。 | 做一个读取名单生成证书的程序，换名单后能再跑，附模板、示例和启动方法。 |
| 可导入的工作流与快捷指令 | 对应平台能加载的流程定义及连接说明；例：新文件校验、跨系统同步、定时报告、家居联动。 | 把取数、清洗和生成报告做成可导入工作流，说明平台、连接与启动条件。 |
| 可调用的接口服务 | 服务程序、调用说明、样例及约定的运行状态；其他程序传入数据取得结果。查询、计算、文件转换、业务登记、AI 分类都是服务用途。 | 做一个运费计算服务，输入重量和目的地返回明细，交启动方法和调用示例。 |
| 软件库与客户端 SDK | 能导入项目的代码包、接口说明和使用样例。库可复用校验或计算逻辑；SDK 可封装对某项服务的调用。 | 把这些校验规则做成可导入的软件包，附用法、样例和依赖说明。 |
| 可嵌入的程序界面组件 | 可接进代码项目的组件包、输入输出说明与演示。例：预约日历、图表、上传器。 | 做一个可复用预约日历组件，附集成示例，说明输入数据和回传事件。 |

条件：程序需要相应运行时，工作流依赖兼容平台与执行环境，服务需要实际运行位置和调用约定。SDK 不代表服务已经开通；流程定义不代表连接已配好。固定步骤的网页/桌面自动操作程序也可放在处理程序中，要说明控制工具与访问条件；采用模型判断下一步时见任务 Agent。CLI 是处理程序的一种入口，定时、事件触发是启动方式，持续运行是部署要求，不分别扩项。构建/测试/部署流程也可作为工作流实例。

## 四、能继续接任务的 AI 助手及其能力包

本组保留 Agent、机器人这些读者会主动寻找的入口，但按实际交出的对象写。下列可以组成同一个系统，不能把它们累计成多个互斥的“AI 产品种类”。

| 可以交付什么 | 拿到什么、怎样用；具体作品例子 | 可以这样跟 AI 说 |
| --- | --- | --- |
| 现有平台里的助手配置 | 可保存或导入的助手设置、提示词、资料与工具连接说明；在兼容平台调用。例：课程答疑、材料整理。 | 在现有平台配置课程答疑助手，使用指定资料和回答规则，交可复用配置。 |
| 可运行的任务 Agent 系统 | 能接收新任务的执行程序、工具连接和运行说明；入口可以是终端、网页或桌面。例：资料研究、分析、编程、浏览器操作。 | 做一个研究助手，能接新问题、补查缺失来源并保存结果，交可运行程序和说明。 |
| 消息机器人程序 | 聊天平台连接、消息处理程序与配置；人在会话里发送指令或文件、接收反馈。例：订单查询、附件处理、知识问答、通知推送。 | 做一个聊天机器人，收到订单表后检查并返回文件，说明平台连接和运行位置。 |
| Agent Skill 能力包 | 兼容助手可以加载的方法说明、脚本和模板；复用一类任务做法，不等于另交一个完整助手。 | 把这套报告流程整理为 Skill，附脚本、模板、使用条件和验证样例。 |
| MCP 工具服务 | 兼容 AI 应用可连接的工具服务与启动配置；例：查库存、读取资料、处理文件。 | 把库存查询封装成 MCP 工具服务，交启动、连接、调用和权限说明。 |
| 模型适配成果 | 针对任务适配的模型文件或适配器、配置与评估材料；在匹配环境加载。例：特定分类或领域任务适配。 | 先评估这些样本是否值得微调，合适时交适配成果、加载方法和评估结果。 |

条件：任务 Agent 要有模型、执行机制、工具及文件/状态存储；平台可提供部分条件，自建时按任务选择云端或本地模型。资料问答可做成网页应用、平台助手或消息机器人，检索组件随对应系统交付，不再按“问答用途”另列产品种类。浏览器/桌面操作要控制工具；机器人要消息接口，固定规则机器人可以不用模型。多 Agent、持续任务、知识检索属于机制或组成要求，写进系统说明，不再分别列一行。模型适配不同于接入资料检索，需单独评估数据、工具和算力。

## 五、能导入、查询或重新计算的数据与资料

| 可以交付什么 | 拿到什么、怎样用；具体作品例子 | 可以这样跟 AI 说 |
| --- | --- | --- |
| 整理好的资料库 | 原文、来源、目录和索引；在文件夹或资料工具中查阅。例：主题阅读材料、项目参考库。 | 整理这些资料，保留原文和来源，交清楚的目录、索引与更新方法。 |
| 结构化数据集 | 可导入的记录及字段、单位、来源和质量说明；例：产品资料、调查结果、标注与评估样本。 | 清洗这些产品记录，统一字段和单位，附来源和异常记录说明。 |
| 可查询数据库 | 数据库文件或建库工程、表关系和示例查询；按条件查找和更新。例：产品、评价、来源的关联记录。 | 把产品、评价和来源做成关联数据库，交建库方法和常用查询。 |
| 带公式的工作簿 | 可计算的表格文件，保留输入、公式和图表；例：预算、排班、成本测算。 | 做一个预算工作簿，改人数和场地费后能重算，标明输入与公式。 |
| 可运行的计算笔记本 | 说明、代码、数据入口与结果保存在同一分析材料里；运行步骤、换数据重算。 | 把这次分析做成可运行笔记本，附依赖、数据入口和重算方法。 |
| 可导入的记录文件 | 目标软件能读取的结构化记录；例：日历课程表、联系人、书目。 | 把课程表做成可导入日历的文件，明确时区和重复规则，附检查示例。 |

条件：字段与来源是数据成果的说明，检查程序属于第三组，检查结果随数据一起交付。数据库和带操作界面的业务应用不同。日历/联系人/书目不是按后缀凑数，而是让人看到内容可以直接进入原来使用的软件。语义检索索引若随问答系统使用，作为系统配套材料说明，不再与原资料库重复计为整套知识产品。

## 六、能阅读、填写、放映或印出来的材料

| 可以交付什么 | 拿到什么、怎样用；具体作品例子 | 可以这样跟 AI 说 |
| --- | --- | --- |
| 可编辑文字稿与报告 | 可继续批注、修订的文档及来源材料；例：文章、研究报告、说明书、课程讲义。 | 按这个命题写可编辑报告，保留论据和来源，并说明待核实之处。 |
| 固定版式出版物 | 页码、目录和版式确定的阅读/打印文件及制作源；例：PDF 手册、作品册。 | 把这份内容做成有目录和页码的 PDF 手册，保留可编辑制作文件。 |
| 可重排电子书 | 阅读器能调字号、跳章节的书籍文件及源稿；例：系列文章合集。 | 把这个系列做成 EPUB，检查目录跳转、图片和字体调整后的阅读效果。 |
| 可编辑演示稿 | 可修改的文字、图表、页面及讲者备注；用于放映与继续编辑。例：课程或产品演示。 | 做一份课程演示稿，保留可编辑对象、图表和讲者备注。 |
| 可填写文件表单 | 可填写并保存的表单文件；例：报名 PDF、访谈记录表。在线提交的问卷应用归第一组。 | 做一份可填写的报名 PDF，说明必填项、保存方式和适用阅读器。 |
| 可打印材料套件 | 按实际尺寸准备的打印文件、源文件与使用规则；例：识别卡、桌游卡牌、题册、纸模或教具。 | 做一套植物识别卡，交正反面打印版、可编辑源文件和裁切说明。 |

条件：这些区分对应不同使用动作，不是看到不同后缀就单列。Word 和 Markdown 可以作为文字稿的不同载体，不分别列项；固定版式与可重排阅读需要不同检查。题库的结构化记录归数据集，题册和教学卡归本组。

## 七、图像、设计稿与可复用视觉资产

| 可以交付什么 | 拿到什么、怎样用；具体作品例子 | 可以这样跟 AI 说 |
| --- | --- | --- |
| 位图成图与透明素材 | 可直接使用的图像文件；例：插画、照片处理、封面、透明背景角色素材。 | 做一组主题插画，按约定尺寸分文件交付，需抠图的部分保留透明背景。 |
| 可编辑矢量图形 | 保留路径和图形对象，能够缩放与修改；例：图标、标志、流程图、关系图。 | 把这套流程做成可编辑矢量图，明确关系，能调整文字、路径和颜色。 |
| 分层设计工程 | 保留文字、图层和布局的制作文件；例：海报、信息图、品牌物料。 | 做活动海报设计稿，文字和图层可编辑，附素材和字体说明。 |
| 可点击的界面原型 | 能体验页面跳转的设计工程及预览；例：预约、购买、课程流程。真实业务另行实现。 | 做预约流程的点击原型，从首页走到提交，标明模拟部分。 |
| 设计系统与视觉组件库 | 可复用的设计组件、样式和示例；在设计工具中保持多页面一致。 | 为这组页面整理组件与样式，交可复用设计库和应用示例。 |

条件：图片、矢量对象、分层工程、原型和设计组件的后续操作不同，值得分别认识；不是按海报/封面/宣传图的题材继续拆。代码里的可嵌入组件归第三组。设计稿要交代软件、字体和素材，不能用预览截图替代约定的可编辑对象。

## 八、声音、视频与动画制作材料

| 可以交付什么 | 拿到什么、怎样用；具体作品例子 | 可以这样跟 AI 说 |
| --- | --- | --- |
| 可播放音频 | 能直接播放或用于剪辑的声音文件；例：配音、播客、音乐、音效。 | 为小游戏做循环配乐，交播放文件并说明循环衔接；先确认可用制作工具。 |
| 可编辑音频工程与音乐事件材料 | 音轨、素材及工程，或可修改音符的音乐事件文件；例：分轨播客、环境声音作品、MIDI 配乐。 | 做雨天散步声音作品，保留旁白、雨声和音乐分轨，附工程和播放版。 |
| 视频成片 | 用于观看或发布的播放文件；例：演示、短片、录屏剪辑。 | 用这些素材剪演示视频，突出实际操作，交播放文件和字幕。 |
| 可编辑视频工程 | 时间轴、素材、字幕与依赖说明；换镜头、调字幕、重新导出。 | 整理这段视频的剪辑工程，素材一并交接，说明打开方法和插件条件。 |

## 随成果交付的说明，不再重复列成成果种类

以下条件放回每项成果旁边，按任务说明，不再占一组“其他交付物”：

- **编辑与复用**：是否保留可编辑源、模板、素材、参数和修改方法。独立模板库可作为对应文档、设计或组件成果交付，但“可复用”不是新形态。
- **运行与安装**：适用平台、依赖、启动方法、入口、安装包和配置；本地、云端、定时、事件触发都是条件或方式。
- **连接与模型**：模型由谁提供，是否需要云端/本地模型接口、业务接口、宿主接口、设备或账号；“不需要云端模型接口”不表示没有软件接口。
- **核对与接管**：来源、数据版本、样例、实际检查结果、已知边界和交接说明。独立委托的研究报告、检查报告仍可作为文档成果；作为配套说明时不重复计数。
- **交付状态**：方案、源工程、运行版、已连接系统分别交到哪一步。原位修改要提供可核对的结果，仓库或压缩包只是交接容器，不是另一种成果。

## 组织自检

1. 网页应用可以承载计算、看板和管理任务，例子丰富但不按每项功能扩张。
2. 游戏保持完整成果入口，不列背包、存档和排行榜；独立资产、配乐和工程按其实际使用方式在对应组介绍。
3. Agent 不再按研究/编程/分析，也不按本地/云端/持续/多代理分别造新条目；机器人不按通知/查询/附件/问答分别造新条目。
4. 自动化不按触发器拆项；实际交付脚本、可导入流程或服务时才明确对象。
5. 分组服务阅读，行数不代表互斥类别数量；先看覆盖是否足够、条目是否具体，再决定文章应保留哪些，不用数字证明全面。
