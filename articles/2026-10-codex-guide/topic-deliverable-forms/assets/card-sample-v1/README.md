## 打开和测试

card-layout-sample-v1.html 是三张原生HTML卡片样张。打开后复制渲染的卡片到135测试，assets/card-sample-v1/cards-body.html为只包含卡片的正文片段。

01-card.png至03-card.png是同样三张卡片的高清图片，按360px阅读宽度、3倍分辨率输出，宽1080px。可另行上传135比较效果。卡片样张测试包-v1.zip包含HTML、图片与说明。

## 样式和内容

每项独立卡片，名称、用途/入口、交付内容、交办句从上到下排列。保留绿色主题，正文及交办句16px/1.65，卡片标题17px，标签13px，内边距12px；全宽阅读，取消三列。

前三项直接来自article-v5.md。中栏按现有句子分为用途和交付内容，网站卡片把用途句聚在一起，文字无删改；没有为新排版重新定义成果、增加功能或改交办句。仅做排版与语句归组，58项清单、全文和两个旧表格版均保持原样。

未增加参考图里的英文副标题和装饰图标，以控制篇幅及复制复杂度。最终效果以实际135预览为准。
