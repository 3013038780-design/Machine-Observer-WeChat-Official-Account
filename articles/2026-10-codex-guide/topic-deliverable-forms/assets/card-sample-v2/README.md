# 带小预览图的卡片样张 v2

日期：2026-10-25。用户同意先给前三张卡片尝试小展示图。本轮只为已有三张样卡加图，未批量替换全文。

## 交付

- card-layout-sample-v2.html：带预览图的三张原生HTML卡片，图片已内嵌，单文件可打开。
- assets/card-sample-v2/cards-body.html：纯卡片正文片段。
- 01-card.png—03-card.png：带图整张卡片，宽1080px，可单独上传135比较。
- previews/01-web.png、02-phone.png、03-desktop.png：三张小界面示意图及对应可编辑HTML/CSS源，宽1002px。
- 带图卡片样张测试包-v2.zip：HTML、整卡图片、小图和说明。

## 设计

小图放在名称下方、文字上方，按334px宽、194px高制作，3倍输出；随卡片等比显示，手机实际高度约190px。产品比较网页突出筛选和来源，手机清单突出勾选，电脑工具突出改名前预览。

均为HTML/CSS与少量SVG形状绘制的静态界面示意，内容虚构，图片底部已标明；不是已完成产品的运行截图，也没有实际开发网站、App或桌面工具。图中按钮、数值和文件名仅解释作品长相。没有使用第三方图片、实际用户数据或产品价格。

卡片原有名称、用途、交付内容、交办句与v1保持一致，正文16px、绿色风格不变；只新增图片，不改58项清单和全文。

## 检查与使用

375/390/760px卡片预览无横向溢出，三张图片全部加载，正文16px；预览图检查内容未超出画布，已查看三张示意图及整卡手机效果。audit.json和previews/audit.json保留检查记录。

打开HTML复制渲染后的卡片到135测试。如果小图未随粘贴带入，可单独上传；也可以直接测试整卡PNG。原生卡片可复制文字，整卡PNG的文字已经成为图片。尚未实际粘贴135，浏览器检查不代表其编辑器一定保留全部样式。

构建先运行scripts/render-card-previews-v1.cjs，再运行scripts/build-card-sample-v2.cjs；可编辑源全部留存。
