# HTML 排版 v2：表格字号修订

## 使用

用浏览器打开 article-v3-layout-v2.html，复制渲染后的正文到 135。内嵌全部图片，无需网络。若粘贴未带入图片，使用 135表格图片-v2.zip 按文件名前两位数字补传；00 为品牌首图，01—32 为表格。保持等比显示。

另存 article-v3-layout-v2-body.html 正文片段与 article-v3-layout-v2-linked.html 本地引用版。v1 保留供比较，当前审阅 v2。

## 修订

第一版把表格按 360px 宽度、17.5px 字号制图，却允许页面在电脑端扩大至 640px，图片文字被同步放大，明显大于正文。该处理不足已修正。

本版表格正文为 16px，分组标签与表头为 15px；仍按三倍分辨率输出 1080px PNG。页面最大宽度改为 384px，含两侧各 12px 留白，实际图宽不超过 360px；桌面呈现接近手机的阅读列宽，避免图片文字继续放大。正文保持 16px / 1.75，绿色配色与首图不变。表格行高 1.4、自动换行、无固定行高，三列比例仍为 25/28/47；保留 18 组 119 项、32 张表格图。

## 检查

375px 页面：图宽 351px，表格实际字号约 15.6px；390/760/1440px 页面：图宽 360px、表格实际字号 16px，正文均为 16px，无横向溢出。检查了全部 32 张表格联系图、手机局部及桌面预览，未见裁切。详见 qa/html-v2/audit.json 与 font-size-check.json。

135 实际粘贴仍未实测；编辑器若扩大图片或正文宽度，图片内文字也会等比变化。本版保证所交付 HTML 的手机和电脑预览比例一致，不代表外部编辑器会保留所有样式。未发表。
