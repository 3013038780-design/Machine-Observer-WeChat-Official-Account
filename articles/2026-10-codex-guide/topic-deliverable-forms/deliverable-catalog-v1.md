# AI 交付形式全景表

2026-10-22。用户认可并要求完整保留；共 28 类。作为新独立专题的素材，非第四篇现行正文要求。分类用于帮助探索，不声称列尽所有格式或当前会话均能直接制作。

| 交付类别 | 可以交付什么 | 常见载体或形式 |
| --- | --- | --- |
| 文字与论述 | 文章、报告、方案、说明书、研究笔记、访谈整理 | 纯文字、Markdown、Word、在线文档 |
| 固定版式出版物 | 正式报告、白皮书、手册、简历、海报、电子书 | PDF、EPUB、排版源文件 |
| 演示与讲述材料 | 汇报、路演、课程、演讲配套材料 | PPTX、在线幻灯片、网页演示、讲稿、演讲备注 |
| 表格与计算模型 | 预算、报价、预测、排期、财务测算、经营模型 | Excel、在线工作簿、带公式和图表的模板 |
| 行列数据 | 产品目录、订单明细、调查结果、清洗后的数据集 | CSV、TSV、工作表 |
| 结构化数据 | 有层次的记录、配置、接口返回、标注结果 | JSON、JSONL、XML、YAML |
| 数据库与查询成果 | 可查询资料库、业务数据表、查询脚本、分析视图 | SQLite、数据库表、SQL、数据导出 |
| 图表与信息图 | 趋势图、关系图、流程图、组织结构、时间线 | PNG、SVG、PDF、可编辑图表源文件 |
| 图片与平面设计 | 插图、封面、海报、图标、产品图、品牌视觉 | 位图、矢量图、透明素材、可编辑设计文件 |
| 界面设计与原型 | 页面设计、应用界面、点击原型、设计规范 | 设计稿、交互原型、组件库、设计变量 |
| 交互报告与分析工具 | 可筛选报告、比较器、计算器、模拟器、数据看板 | HTML、交互笔记本、网页应用 |
| 网站与在线服务 | 官网、专题站、知识库、门户、业务系统 | 网站源码、已部署网站、后台管理界面 |
| 软件与可运行程序 | 小工具、桌面应用、移动应用、插件、命令行工具 | 源代码、安装包、可执行程序、浏览器扩展 |
| 接口与可复用组件 | 给其他程序调用的功能、软件库、组件 | API 服务、SDK、软件包、组件包 |
| 自动化流程 | 一次整理一批文件、按时生成报告、发现变化后处理、在系统间同步数据 | 处理脚本、串联多个步骤的工作流、定时任务、事件触发的服务或机器人 |
| AI 工作能力 | 专门处理某类任务的助手、可复用操作方法、工具连接 | Skill、代理配置、插件、工具服务 |
| 音频 | 配音、播客、音乐、音效、音频剪辑 | WAV、MP3、音频工程、分轨文件 |
| 视频与动画 | 演示视频、教程、宣传片、动态图解、屏幕录制 | MP4、GIF、剪辑工程、动画工程 |
| 视听配套材料 | 分镜、字幕、时间轴、旁白、镜头清单 | 分镜稿、SRT、VTT、字幕文件、制作清单 |
| 三维与空间展示 | 产品模型、场景、角色、可旋转展示、三维动画 | 三维工程、GLB、glTF、OBJ、渲染图、视频 |
| 工程与制造资料 | 尺寸图、零件模型、装配图、加工或打印模型 | CAD 工程、STEP、DXF、STL、技术图纸 |
| 地图与地理成果 | 点位地图、路线、区域分析、空间数据展示 | 交互地图、GeoJSON、KML、GIS 工程 |
| 数学与科学成果 | 推导、计算、仿真、实验分析、可复现研究 | LaTeX、计算笔记本、仿真程序、结果数据、论文 PDF |
| 日历与可导入记录 | 日程、任务、联系人、书目、表单数据 | ICS、VCF、BibTeX、系统导入文件 |
| 模板与复用资产 | 报告模板、演示模板、表格模板、网页模板、素材库 | 模板文件、组件、样式、生成脚本 |
| 验证与交接材料 | 测试结果、来源记录、操作说明、复现步骤、交付清单 | 测试报告、日志、截图、录屏、README |
| 完整工程与发布包 | 可继续开发、运行或部署的一整套成果 | Git 仓库、压缩包、项目目录、容器镜像、部署配置 |
| 既有系统中的修改 | 改好原有文档、更新表格、修复应用、整理资料库 | 已保存的修改、代码差异、PR、系统内更新 |
