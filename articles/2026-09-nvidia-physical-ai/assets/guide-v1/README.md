# 手机图解 v1

2026-09-15，用户明确授权HTML与配图。

六张图均为原创矢量关系/流程示意，保留SVG与生成源，导出1440像素宽PNG。不是具体型号照片，不声称模拟真实机械尺寸或特定车型架构。使用确定性排版保证中文与连线可检查，不以生成式产品外观代替事实。

## 图及依据

1. 辅助减速：一般功能流程，对应正文道路信息与控制说明及NHTSA驾驶辅助资料。
2. 汽车组成：传感器、计算、软件与控制，按既有官方产品/客户资料整理；不作为采购顺序。
3. 驾驶研发：NVIDIA安全报告/仿真文档所述开发活动的编辑归纳，实际流程会交叉反复。
4. 机器人形态/场景：入门示例非穷尽、非互斥标准分类；不证明任何品牌采用。
5. 取放：一般机械臂动作示意，与宇树模拟任务及机器人控制说明呼应，不是实测结果。
6. 产品位置：DRIVE AGX、DriveOS、Jetson、Isaac文档与GR00T模型卡，具体网址见正文来源。

## 复现

- `python3 build.py`：生成SVG、图解Markdown、内联正文与预览HTML。
- `node render.mjs`：使用Playwright及Chrome导出PNG，并检查375/390/430/1000像素视口。
- 可用MO_PLAYWRIGHT_MODULE、MO_CHROME_EXECUTABLE指定本地运行环境。
