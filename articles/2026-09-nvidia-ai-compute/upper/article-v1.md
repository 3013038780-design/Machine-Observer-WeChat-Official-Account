# 算力生意（上）：英伟达的产品版图

一张显卡可以用来打游戏、剪视频，也可以在本地运行 AI 模型。到了数据中心，采购清单里却会出现 GPU 模组、高速网络、整柜液冷，以及成套的软件与服务。

它们都在提供算力，买家要解决的问题却不同：个人用户关心电脑能做什么，企业关心业务能否稳定运行，模型公司和云厂商还要计算大规模部署之后的效率。

英伟达的产品版图，就沿着这些需求展开。**读懂型号，要同时看三件事：它为哪类任务设计，以什么形态交付，以及报价包含什么。**

## 先看用途，再看型号

GPU 是图形处理器。它擅长并行处理大量计算，也因此被用于图形渲染、神经网络和科学计算。CPU 则承担通用程序、系统调度等工作；一台 AI 服务器通常需要两者配合。CUDA 是英伟达让应用调用 GPU 计算能力的软件平台。〔01〕

从个人电脑到数据中心，可以先沿下面几条路径认识产品：

| 使用环境 | 代表产品 | 主要关注点 |
|---|---|---|
| 个人电脑 | GeForce RTX | 游戏、创作、本地 AI |
| 专业工作站 | RTX PRO | 大型专业任务、显存与部署条件 |
| 通用加速服务器 | L4、L40S、RTX PRO Server | 推理、视频、图形及混合业务 |
| 大型 AI 系统 | H200、B200、B300、Rubin | 模型规模、多 GPU 协作与系统效率 |

这是按使用环境画的地图，产品之间存在交叉。例如 RTX PRO 既有工作站版，也有服务器版；数据中心 GPU 可以参与训练，也可以做推理。用途不能只靠名称里的一个字母判断。〔02〕〔03〕〔04〕〔05〕

在这张地图之外，还有面向机器人等设备的 Jetson，以及 DGX Spark、DGX Station 这样的桌面 AI 整机。它们的部署方式不同，不能直接塞进“单张显卡”的价格排名。本文聚焦个人电脑、工作站与数据中心之间的产品选择。〔06〕〔07〕

### 名字里有几层信息？

以 **GeForce RTX 5070 Ti** 为例，GeForce 是产品系列，RTX 对应英伟达的图形与 AI 技术体系，5070 Ti 是具体型号。Ti 属于型号后缀，不能脱离规格理解成一个固定的性能增幅。〔02〕

Blackwell、Hopper、Rubin 则属于架构或平台代际名称。同一个 Blackwell 名称下，可以同时存在 GeForce、RTX PRO 和数据中心产品，它们的显存、互联、功耗与使用环境并不相同。〔02〕〔03〕〔05〕〔08〕

因此，问“Blackwell 多少钱”，范围仍然太大；问“美国市场某款 RTX 5090 的哪个厂商版本、什么库存状态”，才接近可以回答的报价问题。

## 一台电脑，先遇到的是显存边界

游戏和视频制作，通常从 GeForce 产品中筛选：看目标分辨率、渲染任务、视频编解码需求，再看预算。切换到本地 AI，选型顺序常常需要改变——先确认任务能否装进显存。〔02〕〔09〕

显存相当于 GPU 工作时手边的空间。模型权重、运行中的中间结果，以及用于保存上下文计算状态的缓存，都会占用它。模型文件能放进硬盘，不代表能完整放进 GPU 显存。〔09〕

一个容易误判的例子：**RTX 5070 配备 12 GB 显存，RTX 5060 Ti 则有 16 GB 和 8 GB 两种版本。** 对于显存需求超过前者容量的本地任务，后者的 16 GB 版本可能更值得评估。但更大显存并不自动带来更快速度，仍要看带宽、计算能力和实际软件表现。〔02〕

> 显存回答“放不放得下”，显存带宽回答“数据搬得够不够快”，计算能力回答“数据到位后算得有多快”。任务由哪个环节限制，决定升级哪项规格才有用。〔10〕

### 算一笔能看懂的显存账

假设一个模型有 **700 亿个参数**，每个参数按 **4 bit** 储存，单算权重的理论体积就是：

> 700 亿 × 4 ÷ 8 = 350 亿字节，约 **35 GB**。

这里采用十进制 GB，是简化估算，不是某款模型的实测。

实际运行还要为量化元数据、部分较高精度权重、上下文缓存和计算开销留空间。因此，不能承诺一张 **32 GB 的 RTX 5090** 完整承载这一假设下的所有 GPU 内存需求。

把一部分数据放到 CPU 内存、采用不同量化方案或拆到多张卡上，属于另外的部署方案，也会改变性能。〔02〕〔09〕〔11〕

这也是“能跑”和“好用”之间的距离。选卡之前，至少要明确模型、量化方式、上下文长度，以及同时服务的请求量；只说“跑一个大模型”，不足以决定买哪张卡。

### 为什么又会看到 RTX PRO？

当大型场景、专业模拟或本地 AI 任务需要更大单卡显存时，就会进入 RTX PRO 的范围。**RTX PRO 6000 Blackwell 工作站版配有 96 GB GDDR7 ECC 显存**，ECC 提供内存错误检测与纠正能力。它的设计重点包括专业图形、AI 开发和模拟等任务。〔03〕〔12〕

但“6000”也不是完整采购名称。同系列中，工作站版最大功耗为 **600 W**，Max-Q 工作站版为 **300 W**，服务器版为 **400–600 W**，散热方案也不同。服务器版的被动散热，需要服务器风道配合。不能因为显存容量相同，就把几个版本当成可以直接互换的产品。〔03〕

## 数据中心，也有不同的用法

企业的视频处理、图形服务与大模型训练，对硬件的要求并不相同。L4、L40S 和 RTX PRO Server 说明了一件事：进入数据中心，并不意味着所有任务都应采购最昂贵的训练系统。〔04〕〔13〕〔14〕

L4 配有 **24 GB 显存**，最大热设计功耗为 **72 W**，采用半高单槽形态，面向视频、AI 和图形等任务。L40S 则配有 **48 GB GDDR6 ECC 显存**，最大功耗 **350 W**，覆盖推理、渲染等混合工作负载。两者代表了不同的部署取舍，不构成适用于所有任务的性能排序。〔13〕〔14〕

当任务需要更大的模型、更高吞吐量，以及更密集的多 GPU 通信，Hopper、Blackwell 和 Rubin 系列系统就成为主要考察对象。先分清训练与推理，才能读懂它们为什么升级。

**训练**通过数据更新模型参数；**微调**在已有模型基础上继续训练，让它更适应目标任务；**推理**使用模型处理新的输入、生成结果。它们不是互不相通的硬件门类：同一款 GPU 可以参与不同阶段，只是具体任务对计算、显存和通信的要求不同。英伟达的系统文档也同时列出训练、微调和推理等用途。〔05〕〔15〕

### H100、H200、B200、B300，该怎么连起来看？

H100 与 H200 属于 Hopper；B200 属于 Blackwell，B300 属于 Blackwell Ultra。下面只选定明确版本，比较显存容量与带宽这组最直观的差异。〔05〕〔08〕〔16〕

| GPU 版本 | 单 GPU 标称显存 | 显存带宽 |
|---|---|---|
| H100 SXM | 80 GB | 3.35 TB/s |
| H200 SXM | 141 GB HBM3e | 4.8 TB/s |
| B200 SXM | 180 GB HBM3e | 最高 8 TB/s |
| B300 SXM | 288 GB HBM3e | 最高 8 TB/s |

这张表比较的是单 GPU 的官方标称配置，不能当作应用可用显存表，也不是速度排行榜。H100 的 NVL 版本就有不同的规格，所以看到裸写的“H100 报价”，应先补问版本。〔05〕〔16〕

**B200 到 B300 的这组变化尤其有解释力：显存容量增加，表列最高显存带宽却相同。** 它意味着能承载的模型与缓存规模发生变化，但不能仅凭容量增幅，推导出任务速度也按相同比例增长。性能还取决于计算精度、模型结构、软件和并发设置。

GDDR 与 HBM 也值得区分。前面 GeForce、RTX PRO 使用的是 GDDR 系列显存；表中 H200、B200、B300 使用 HBM。HBM 是高带宽内存，采用堆叠等技术路线，服务于高带宽需求。讨论“显存多大”和“用哪种显存”，是在讨论不同维度。〔02〕〔03〕〔05〕〔31〕

### Rubin 已走到哪一步？

截至本文核查日 **2026 年 9 月 12 日**，不能再把 Vera Rubin 简单写成尚未出货的路线图。英伟达 **2026 年 8 月**发布的季度报告明确表示，Vera Rubin 已在其 **2027 财年第三季度**开始生产出货，并将与 Blackwell 系统同时供货。这里的财年名称不能直接当成自然年。〔18〕

当前美国产品页列出的 Rubin 单 GPU 显存为 **288 GB HBM4**。但技术博客与当前产品页的部分带宽数字存在差异，本文不把这些指标放进横向比较。**开始出货、某客户已经部署、普通采购方能拿到什么交期，是三个不同问题。** 具体项目仍需核实供应商提供的配置与交付承诺。〔17〕〔18〕〔19〕

旧型号同样不会因新型号出现而自动失去价值。已有软件适配、机器配置、采购成本与实际任务，都会影响是否值得换代。选型要回答的是“这项业务需要什么”，而不是“目录最后一页写了什么”。

## 从一颗 GPU，到一套能运行的系统

到了这里，产品名称会出现另一种变化：B300、GB300、HGX、DGX、NVL72。它们不在同一层级，不能排成一列直接比较价格。

**PCIe 与 SXM，先决定安装方式。** PCIe 卡通过插槽接入主机；SXM 是用于相应服务器底板的 GPU 模组形态。以 H100 为例，官方就分别列出 SXM 与 PCIe 形态的 NVL 产品。买到 GPU，还需要兼容的底板、供电、散热和整机配置。〔16〕

**HGX 是多 GPU 平台。** HGX B300 底板集成 **8 个 B300 GPU**，通过 NVLink 与交换组件协作，整机厂商再围绕它配置服务器。HGX B300 的价格因此不能与一张 B300 的价格混为一谈。〔05〕

**GB300 NVL72 是机柜级系统。** 官方配置包含 **72 个 Blackwell Ultra GPU 与 36 个 Grace CPU**，采用液冷。这里的采购单位已经从单卡走到整套机柜平台，交付还涉及机房条件。它也不是把若干 HGX 服务器简单相加后的另一个名字。〔08〕

> 单 GPU／模组 → 多 GPU 底板与服务器 → 机柜与集群。
>
> 这是理解采购规模的层次图，不是一份可以随意拼装的兼容清单。不同系统有各自的设计与供应路径。

**DGX 是英伟达的整套 AI 系统与平台方案**，涵盖硬件、软件、管理和支持；具体要看 DGX 后面的产品名称。**MGX 则是模块化参考架构**，供合作伙伴设计服务器和机柜。HGX、DGX、MGX 各自说明平台或交付方式，并不是三种 GPU。〔07〕〔20〕

### 多买几张卡，为什么还要买网络？

模型拆到多 GPU 上，或者训练过程需要同步计算结果时，GPU 之间必须交换数据。通信拖慢，单卡的计算能力就可能等在原地。〔21〕

可以先记住两层：NVLink 与 NVSwitch 用于系统内的高速 GPU 互联；跨服务器扩展还会涉及网卡、交换机与网络设计。英伟达在这里提供 Quantum InfiniBand、Spectrum-X Ethernet、ConnectX 和 BlueField 等产品。它销售的范围，也随之延伸到 GPU 周围的基础设施。〔22〕〔23〕

软件同样决定硬件如何被使用。CUDA 提供 GPU 计算的软件基础；TensorRT 家族优化模型推理；NCCL 处理多 GPU、多节点之间的通信。比较两套采购方案时，应用适配、软件版本和支持服务也应进入清单。〔01〕〔11〕〔21〕

## 价格表，必须先注明是哪一种价格

“英伟达芯片的官方出厂价”听起来像一个统一数字，实际上需要先明确对象：是显卡的官方发布起价、官方商城挂牌价，还是厂商卖给合作伙伴的批量价格？公开零售页面不能证明后者。

本文将能查到的价格分成两组：**官方发布起价用于理解产品定位，当前可读取的销售页报价用于观察具体商品。** 两组都不等于所有买家的成交价。

## 看一张采购单，问到哪一步才算看懂？

选型最终需要从型号回到任务。实际沟通可以沿下面的顺序展开：

- **做什么工作？** 游戏、渲染、视频、模型训练、微调还是推理；具体软件与模型是什么。
- **买的是什么版本？** 完整型号、显存、PCIe 或 SXM、厂商料号；单卡、套件、服务器还是机柜。
- **任务能否承载？** 显存之外，还要说明上下文、并发、目标响应速度和允许采用的量化方案。
- **怎么证明跑得快？** 比较相同模型、精度、输入输出长度、软件版本和质量要求下的测试；分清单请求延迟与整体吞吐量。
- **现场能否部署？** 主机兼容、供电、散热、网络、机房条件是否已经具备。
- **这笔钱包含什么？** 税费、安装、互联组件、软件、服务、保修和交期；哪些还需要另买。

一个写着“算力更高”的报价，仍然可能没有回答业务问题。TOPS 与 FLOPS 衡量运算吞吐，比较之前还要看数字精度、运算类型，以及是否采用稀疏条件；它们不能直接换算成某个应用的实际速度。英伟达自己的规格表也会区分这些条件。〔10〕〔16〕〔19〕

**英伟达的产品版图，最终是一张任务与部署方式的地图。** GeForce 解决个人电脑上的工作，RTX PRO 扩展专业场景，数据中心 GPU 与系统平台承接更大的模型和协作规模。理解它们的价值，要把任务、硬件、软件和交付放在同一张采购单上。

下一篇继续往后走：这些设备进入云厂商和模型服务商之后，算力怎样被租赁、调用，又怎样变成按 Token 计费的服务。
