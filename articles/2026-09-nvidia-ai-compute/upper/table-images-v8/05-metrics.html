参数与英文它回答什么问题？
容量
Capacity		能放多少数据？ 内存、显存和硬盘都可以用 GB、TB 表示容量，但它们是不同位置的空间。
显存带宽
Memory Bandwidth		GPU 与显存之间，每秒能传输多少数据？ 常用 GB/s、TB/s 表示；这里的 s 是秒。
GPU 互联带宽
GPU Interconnect Bandwidth		不同 GPU 之间，每秒能交换多少数据？ 影响多卡协作，和显存带宽不是同一个指标。
算力
Compute Performance		处理器能完成多少计算？ 常见指标有 FLOPS（Floating-Point Operations per Second，每秒浮点运算次数）与 TOPS（Trillion Operations per Second，每秒万亿次运算）；比较时还要看精度与测试条件。
