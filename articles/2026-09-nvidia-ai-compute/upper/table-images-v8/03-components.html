名称与英文全称中文含义与作用
CPU
Central Processing Unit		中央处理器。 执行通用程序、处理控制逻辑，并参与组织和调度计算任务。
GPU
Graphics Processing Unit		图形处理器。 擅长并行处理大量计算，既用于生成画面，也用于 AI 等任务；通常与 CPU 配合。
RAM
Random Access Memory		随机存取存储器。 电脑配置里的“内存”通常指系统内存，用来临时存放运行中的程序与数据；常见系统内存断电后不保留内容。
VRAM
Video Random Access Memory		显存。 GPU 工作时使用的内存，保存画面数据、模型权重和计算过程中的数据；独立显卡通常自带专用显存。
SSD
Solid-State Drive		固态硬盘。 长期保存系统、软件、文件和模型，断电后仍能保留数据。
HDD
Hard Disk Drive		机械硬盘。 同样用于长期保存数据，采用磁性盘片，与 SSD 的存储方式不同。
