# 参考文章与逻辑修订

用户提供两篇公众号文章文本（未提供原文链接，图片仅有占位符）。仅提取组织方式与选题线索，不把缺失图片的表格当作已知数据，也不复制其他账号署名、免责声明、营销文案。

用户随后澄清：商业叙事可以保留，主要问题是结构混乱，要求知识扎实且容易理解。因此 v3 不机械照搬百科目录，采用以下因果顺序：

1. 产品总图：按工作环境区分产品家族，再澄清架构与型号。
2. 个人电脑：任务变化如何改变图形、计算与显存需求。
3. 专业工作：容量、软件认证与支持为何构成另一条产品线。
4. 数据中心：先训练/推理，再解释容量、带宽与通信，再看型号差异。
5. 设备端：体积、电力、传感器、响应约束为何形成 Jetson/DRIVE。
6. 系统与价格：先明确GPU、平台、机柜交付单位，再比较报价。

参考文中的“当前RTX A系列”“Orin新一代旗舰”等表述不能直接沿用；当前目录还需覆盖RTX PRO Blackwell、Jetson Thor及已公布但尚待供货的产品。不得沿用“消费卡兼容性无法保证”“某型号是AI入门首选”“支持某级自动驾驶即可代表整车能力”等宽泛结论。不沿用条件不清的FP8/FP16排名或跨精度性能倍数。
