内容提要：个人用户需要游戏、创作和本地 AI；企业团队需要设计、研发和部署；云厂商与算力运营商需要组织大规模计算；设备厂商则把计算装进机器人和汽车。英伟达围绕这些需求提供不同产品：从 GPU 等计算部件，到整机与系统，再到开发、部署和仿真软件。客户要完成的工作，决定了这些产品如何组合。一个玩家购买显卡，是为了让游戏运行得更流畅；一家设计公司配置工作站，是为了让设计师处理复杂项目；一家提供 AI 服务的公司建设计算集群，是为了让大量用户能够持续调用模型。他们都可能使用英伟达产品，但需要解决的问题不同，买到或使用的东西也不同。本文以这些用户的工作为线索，梳理英伟达的主要产品线：从个人显卡、专业电脑，到数据中心计算与网络，再到机器人、汽车，以及贯穿其中的软件和云平台。重点是看清它提供什么、各类产品有什么关系。实际项目可以根据需求与兼容性，组合不同厂商的硬件、软件和开源工具；文中的场景用于说明产品用途，并不意味着需要购买或使用英伟达的整套产品。个人电脑、专业创作与服务器环境1个人用户：游戏、创作与本地 AI（1）游戏玩家与创作者对玩家来说，显卡影响游戏画面的计算与呈现；对视频和三维创作者来说，它可以加速部分制作、渲染和导出工作。个人采购的话，认准英伟达的 GeForce 系列，RTX 50 从 5050 到 5090 覆盖不同档次，笔记本和台式机规格不同、需分开看。不过买之前要分清三个概念：GeForce 是产品系列，Blackwell 是技术架构，RTX 5090 才是具体型号。[01]此外，GPU与显卡很容易混淆。GPU 只是负责计算的芯片（大脑🧠），显卡是包含 GPU、显存、供电的一整块板卡。GPU 擅长把适合拆分的运算分配给许多计算单元同时处理。画面渲染有大量这类工作，AI 中的许多计算也适合这种方式，所以同一类产品能同时服务游戏、创作和 AI。[03]但 GPU 不是万能的，电脑里还有 CPU（负责通用运算和指挥调度）、内存（临时存数据）、硬盘（长期存文件），比如剪视频时 GPU 只负责加速其中适合它的环节，读取素材、输出成片还得靠其他部件配合。[04] [05]软件中的任务由 CPU、GPU 等部件分工处理，但是并非所有操作都会因为显卡升级而变快。驱动帮助操作系统和应用使用显卡；NVIDIA Studio 是面向创作者的软硬件配套体系。剪辑师仍在使用 Premiere、达芬奇等软件，Studio 提供的是背后的配套。[06]（2）个人：使用 AI 在线使用通过 ChatGPT、Kimi 等官方网站或应用，用户可以直接提问、提交资料并获取结果，无需自行安装和维护模型。对于这类使用方式，本地显卡通常不是决定模型生成速度的主要因素。在线使用视频生成也是如此。例如，通过在线服务使用 Seedance 时，生成任务由云端处理，速度主要取决于服务端的计算与调度。将生成的视频下载到本地后，剪辑、特效和渲染等环节才可能进一步使用本机 GPU。[07]但是本地部署AI是将模型文件和运行软件下载到自己的设备，由本机完成模型计算，常见模型包括：这些模型提供可下载的权重，即模型训练得到的参数，具体使用范围以许可证为准。其中，蒸馏版是学习较大模型能力的较小模型，便于在资源更有限的设备上运行，但不等同于完整在线服务。08] [09] [10]本地部署主要适用于以下场景：数据不便上传（如敏感资料）、需要离线使用、以及希望对模型有更强的控制权（如固定模型版本、微调模型）。相应地，用户需要自行承担设备、配置和维护成本。想在本地跑 AI 模型，主要看你买的东西能不能"装得下、跑得快"。关键在于三点：处理器（CPU 能跑，但GPU明显更快）、显存（决定能装多大的模型，不够用就卡或跑不起来，而且显存和内存不能互相顶替）、还有显卡与软件的配合（跑模型的软件得支持你的显卡才行）。所以买设备时不要只看游戏跑分，要看你想跑的模型需要多少显存。[12]2企业用户：做设计和研发企业里的使用者可能是设计师、工程师、研究员或程序员。专业设计关注项目与软件，模型研发还需要开发环境、实验和部署能力。设计师与工程师建筑师用 Revit 建立建筑模型，机械工程师用 SOLIDWORKS 设计零件和装配结构。随着项目规模扩大，他们需要根据工作要求配置电脑，兼顾处理能力、内存容量和软件运行的稳定性。[13] [14]面向这类用途销售的专业电脑，也常被称为“工作站”，既有台式主机，也有笔记本。RTX PRO 则是可以装在这类电脑里的专业 GPU；需要经常携带设备的用户，也可以选择搭载 RTX PRO 笔记本 GPU 的电脑。[15] [16]RTX PRO 的价值包括部分型号提供的大显存，以及专业软件认证、企业驱动与支持。[17]研究员与程序员企业要使用 AI，首先需要决定是购买现成应用，还是自行开发。以新增企业客服功能为例，（1）如果购买现成客服软件，企业只需要配置业务资料与服务流程即可；（2）如果选择自行开发，则需要把客户提问、业务数据查询和模型回答连接起来。若企业准备自行开发，有三种选择：调用现成模型 API、租用云端算力自行部署，或本地部署。第一种，调用阿里云百炼的千问模型 API。 API 就是程序调用接口，企业通过它向阿里云已经运行好的模型发送内容、取得回答，无需自己部署这部分模型服务。[20]企业系统负责取得订单事实，千问负责根据这些信息生成回答。[21]第二种，租用阿里云 GPU 云服务器，自行部署千问模型。 企业租到的是远程计算资源，研发人员需要下载适合的可部署模型版本，安装运行软件。阿里云负责底层硬件，企业负责所部署模型服务的更新与运行管理。[22]前两种方式最终都可以通过 API 接入客服系统，区别在于模型服务由谁部署和维护。第三种，在企业自己的设备上部署模型，则还需要企业配置和维护相应硬件。这些方式也可以组合，例如在自己的电脑上开发测试，再部署到租用的云端服务器；下面以选择在自己的设备上开发文字客服助手的团队为例，说明模型、软件和硬件如何配合。团队先选一个可以本地运行的语言模型，再测试回答质量、调整模型，并把它接入客服程序。英伟达除了提供硬件，也提供可供开发者选用的模型，例如 Nemotron 系列。[23]调整模型和使用模型，是这个项目中不同的计算任务。 如果团队用整理好的客服问答样本调整模型参数，让它更好地遵循企业的回复格式与处理要求，这属于训练；在已有模型基础上继续训练，称为微调。模型收到一个新问题并生成回答，则是在进行推理。此外团队还需要准备数据、评估效果和维护程序，训练与推理并不涵盖项目的全部工作。[24]问开发工具选择开发客服助手时，软件工具可以按使用场景层层选择：最底层是英伟达的 CUDA 并行计算平台及其配套开发工具包 CUDA Toolkit，这是调用英伟达 GPU 算力的基础。在此之上按需求选工具：需要微调模型时用 NeMo；模型定 型后要优化推理速度时用 TensorRT（其中 TensorRT-LLM 专为大语言模型设计）；想快速部署现成的模型服务时用 NIM（预先打包好的推理服务）；如果需要生产环境的长期支持、安全更新与维护，则可以选择企业级的 NVIDIA AI Enterprise 平台。[26] [27][29] [30]问硬件工具选择设备选择上，本机实验可以买配好 RTX PRO 显卡的整机，也可以给兼容台式机单独加装显卡；还可以选英伟达的小型桌面 AI 电脑 DGX Spark（CPU+GPU 一体、统一内存，可本地开发测试），但要注意统一内存"装得下"不等于"跑得快"，带宽和软件实现同样关键。不同 GPU 定位不同也有交叉：数据中心的 A100 兼顾训练与推理，L40S 兼顾 AI 与图形视频；更大规模的需求则要上服务器甚至多台协作。至此分工明确：模型负责生成、GPU 负责计算、软件负责部署接入；上线后若并发量增大，就需要更多算力和运维保障。硬件选择的原则是：先明确模型和软件方案，再检查现有设备能否跑、要不要升级，并结合预算和实测反复调整。注意三件事是分开的——能不能跑、跑多快、回答质量如何：只要软件兼容、内存够，设备差一般只是变慢，质量不一定下降；真正影响质量的是为了迁就设备换小模型或降低精度。另外，设备需求取决于具体工作量（模型大小、训练方法、输入长度、并发数量），不能只看"训练"还是"推理"就定显卡。3云厂商与算力运营商企业将客服模型部署到云上以后，模型仍要在实际的服务器上运行。腾讯云、阿里云等云厂商提供这些计算资源；经营算力服务的企业也常被称为算力运营商，两者的业务可能重叠。服务器集中部署在数据中心等设施中，由相应团队管理。[37] [38]对服务商而言，要解决的问题是：怎样让许多客户同时使用这些设备，完成模型训练、推理或其他计算工作？这需要从一台服务器开始，再考虑多台设备协作，最后把供电、散热和运行管理配齐。 一台服务器怎么跑模型服务器也是计算机，只是按业务需求配置：硬盘存模型文件、内存接数据、CPU 跑服务程序、GPU 跑模型计算。数据中心 GPU 与个人显卡定位不同——个人显卡兼顾游戏显示，数据中心 GPU 强调装模型、传数据、多卡协作。英伟达这条产品线包括 A100、H100、H200和 Blackwell 系列的 B200、B300，新一代 Rubin 平台延续同一方向（不按"训练卡/推理卡"严格区分）。内存技术也不同：RTX 5090 用 GDDR7，H200 用 HBM3e（HBM 高带宽内存是芯片技术，不是额外设备）；CPU 方面英伟达有 Grace、Vera，与GPU 的模型计算相互配合。[39] [35][12] [40] [41] 多台服务器怎么协作假设越来越多客户同时向模型提问，一台服务器已经忙不过来。服务商可以在更多设备上运行模型副本，把不同请求分配过去。有两个选择：多设备跑模型副本分发请求，或把大模型拆到多张 GPU 上（设备间要交换数据，光堆算力不够）。英伟达为此提供了两类连接能力。互连产品：NVLink / NVLink Switch（GPU 高速互连）、ConnectX 网卡、Spectrum-X 以太网、Quantum InfiniBand（跨服务器通信）、BlueField DPU（分担网络、存储、安全处理）。注意"带宽"有三个对象：显存带宽、GPU 互连、服务器网络，不能一概而论。系统集成方式：HGX（多 GPU 平台）、MGX（模块化参考架构）、DGX（系统家族）——三者不是显卡型号；GB200 把 Grace CPU 与 Blackwell GPU 组合，GB200 NVL72 是液冷机柜，更大规模有 DGX SuperPOD。 怎么持续运营设备-运维团队设备买齐只相当于厨房建好了，能不能稳定开门营业是另一回事，运维管理软件和运维团队（人）日常要处理四件事：任务调度：客人下单后派哪个厨师做。对应到模型服务，就是客户提问进来后，系统决定交给哪个模型副本回答，让设备既不闲置也不排队；设备监测：像盯着厨师有没有生病，随时发现 GPU 温度异常、性能下降等问题；故障处理：真有设备坏了，要把它手里的活立刻挪给别的设备，不能让整个服务停摆；按用量调整资源：中午客多就多排人手，下午客少就收缩——资源跟着流量走，避免浪费。经营上还有两种模式：托管和出租。托管模型像点外卖，服务商连"做菜带送餐"全包，帮你管好模型和请求分配；出租云服务器像只租厨房，服务商保证机器能开机，里面的应用和模型由客户自己管。英伟达自己也经营这样的环境：DGX
