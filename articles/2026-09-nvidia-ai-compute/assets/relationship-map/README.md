# 全文横向逻辑关系图 · 当前版本

本版按用户确认的三个部分：个人、企业、云厂商与算力运营商。替代此前被否定的分组长图及全二叉判断图。

## 图中逻辑

1. 个人分出游戏/创作与个人AI；个人AI再分在线与本地，两者按需使用。本地设备是否满足需求，才使用条件分叉。
2. 企业分出专业设计和AI应用；AI应用分购买现成、自行开发；自行开发同时展开API、租云算力自行部署、自有设备部署三种方案。API直接进入可用应用，不错误地要求客户自行部署模型。
3. 两条自行部署路径共同连接模型、软件、设备三个配合要素。软件标注不同功能和按需选择，不写成CUDA→NeMo→TensorRT→NIM的固定步骤。
4. 云厂商的计算、通信、系统和运维是四个共同支撑服务的方面。模型多副本与多GPU分担是可结合的扩展方法，不画成互斥选择。
5. 同一客户可进入多个任务场景；专业电脑、GPU、模型、云服务不混为同一层级的替代品。
